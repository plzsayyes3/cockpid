# Project Town tiles

Lightweight pixel materials for Project Town.

Grid rules:
- room/floor tile: 24×24 px
- material textures: 8×8 px
- rug pattern: 16×16 px
- tiles are rendered at native size and repeated; no bitmap scaling is required for the room background
- Project Town character/action logic is independent from these visual materials

Assets:
- `floor-01.png` — warm wood floor
- `wall-01.png` — warm cream wall/panel material
- `wood-dark.png` — dark wood trim
- `wood-light.png` — desk/counter wood
- `rug-green.png` — small decorative rest-area rug pattern
